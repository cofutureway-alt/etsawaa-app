## 1) i18n

| العنصر | القيمة |
|---|---|
| المكتبة | `i18next` v25 + `react-i18next` v16 |
| اللغات | `ar` (افتراضي) + `en` |
| القواميس | `app/lib/i18n/{ar,en}.ts` — **1841 مفتاحاً لكل منهما** |
| المساحة | `translation` واحدة (لا namespaces) |
| البديل | `fallbackLng: "ar"` |
| التحميل | متزامن (موارد ثابتة) — لا وميض مفاتيح |

### إدارة المثيل
- السيرفر: `createI18n(locale)` جديد لكل طلب.
- العميل: `clientInstance` مفرد + `changeLanguage`.

### المزوّد
`root.tsx:48-54`:
```tsx
<I18nextProvider i18n={getI18n(loaderData.locale)}>
  <html lang={locale} dir={dirFor(locale)}>
```

### بادئات المفاتيح — 71 بادئة
أكبرها: `store` (128)، `productWizard` (89)، `vendorOnboarding` (88)، `auth` (74)، `catalog` (72)، `ui` (71)، `order`/`checkout` (70 لكل).

**مشكلة تسمية:** بادئات مشفّرة قصيرة: `st` (61)، `dim` (44)، `cp` (36)، `et` (34)، `ve` (33)، `rf` (26)، `bl` (24)، `wd`/`pn` (22). غير متسقة مع المفاتيح الكاملة.

### RTL
- `<html dir>` على السيرفر.
- خصائص منطقية في Tailwind: `start-`, `end-`, `ps-`, `pe-`, `border-s`.
- `.mirr` → `scaleX(-1)` تحت `[dir="rtl"]` (لأسهم/chevrons).
- `.num` → `unicode-bidi: isolate` + `direction: inherit`.

### الاختبار
`tests/i18n-keys.test.ts` — تساوي مجموعات المفاتيح AR/EN، لا قيم فارغة، لا إيموجي، تساوي `{{var}}`، `switchLocalePath` يحفظ path/query/hash.

```css
      --container-max: 1200px, sidebar tokens, footer tokens */
```

مطابق تماماً لـ `branding/colors.txt`. ✔

### حقن التوكنات من DB
```ts
// app/lib/tokens.ts
EDITABLE_COLOR_TOKENS = ["primary","action","actionHover","ink"];   // 4 فقط
tokensToCss(tokens) → ":root{--color-primary:…;…}"
```
```tsx
// root.tsx:86 — بعد <Links/> لأن React 19 يرفع <style precedence> فوقه
<style dangerouslySetInnerHTML={{__html: tokensToCss(loaderData.design)}} />
```

**سلسلة كاملة:** `settings.design` → `loadPublicSettings` → root loader → `<style>` → `:root` → tailwind utilities. تغيير لون من `/admin/settings` يعيد تنسيق الموقع بلا كود. ✔

### Tailwind v4
لا `tailwind.config.*` ولا `postcss.config.*`. `globals.css`:
```css
@import "tailwindcss";
@import "./tokens.css";
@theme inline { --color-primary: var(--color-primary); … }
```
التعريف ذاتي المرجع → الأدوات تقرأ التوكنات وقت التشغيل، فيمرّر تجاوز DB عبر كل شيء.

### الخطوط

- `/fonts/cairo-var-arabic.woff2` (30,896 بايت)
- `/fonts/cairo-var-latin.woff2` (33,820 بايت)

## 5) مكتبة الميديا

### المجلدات
`media_folders` — `depth CHECK 1..3` + trigger `fn_media_folder_depth` يرمي `folder_depth_limit`، ويضمن نفس المالك للأب. الواجهة: زر "مجلد جديد" معطّل عند `depth >= 3`.

### الملفات
`media_files` (owner, folder, bucket, path UNIQUE `u/{uid}/{uuid}.{ext}`, mime, size, kind, dims, `deleted_at`). ترقيم 20/صفحة، بحث `ilike` على الأبناء.

### الرفع
XHR (لا supabase-js) لـ progress + abort + retry + إلغاء. `x-upsert: false`.

### الحدود
`media.shared.ts` + `settings.media`:
- `allowed_mimes[]`
- `max_image_mb` (5) / `max_video_mb` (50) / `max_pdf_mb` (10)
- `max_dimensions_px` (4000)

**عيب مؤكد:** `max_dimensions_px` **مخزَّن وقابل للتعديل وغير مطبَّق في أي مكان** — لا في `validateUpload` ولا في دالة Edge.

### منتقي الميديا
`MediaPickerDialog` — Dialog يلفّ `MediaLibraryCore` في وضع الاختيار (`single`/`multi` + ترشيح أنواع). مستخدم في: معالج المنتج، مصفوفة المتغيرات، الخصائص، الماركات، الأقسام، onboarding البائع، متجر البائع.

**مطابقة `AGENT §24`:** "لا حقول ملف عادية في المنتج النهائي" — تتحقق في كل مكان عدا بانرات/محتوى المدونة (`admin/banners.tsx` يطلب نص مسار).

### الحذف الآمن
soft-delete → `fn_media_usage(path)` → إن غير مستخدم: حذف Storage + الصف؛ وإلا toast `media.deletedSoftInUse`.

**عيب مؤكد:** `fn_media_usage` يحتوي فرعاً بـ **`where false`** placeholder، والمسح لا يغطي المنتجات/المنشورات/البانرات/الأفاتارات. حذف صورة مستخدمة في منتج قد يمرّ. التعليق يعترف: «phase 03+ extends the UNION».

### الكاش
`app/routes/api/media.ts` — GET `/api/media?path=`، يفحص `^u/[uuid]/[A-Za-z0-9._-]+$`، يعيد البايتات بـ `Cache-Control: public, max-age=31536000, immutable` + `nosniff`.
`media-cache.server.ts` — LRU داخلي، 120 عنصراً.

### تناقض مؤكد
مكوّنان للصور:
- `MediaImg` (متجر — عبر proxy)
- `MediaImage` (أدمن/بائع — رابط Supabase مباشر)

و`mediaSrcSet()` في `media.shared.ts:73` **مستخدم صفر مرة** (تحقق: البحث يعيد التعريف فقط). تعليق `MediaImg` يوضح أن تحويلات العرض ترجع 403 على هذا المشروع.

## 8) نقاط جودة حقيقية

- نظام توكنات مغلق من البداية للنهاية (DB → CSS → Tailwind → كل مكوّن).
- `tokens.test.ts` يفحص تباين WCAG AA على 6 توكنات + تناظر `contrastRatio` + إخراج `:root` الدقيق.
- خط عربي variable self-hosted مع preload بلا أي اعتماد خارجي.
- كل مكوّن UI يصرّح بحالات idle/hover/focus/disabled/loading.
- مكتبة ميديا مبنية بدقة: عمق 3، RLS مالك، رفع بـ progress، نقل بـ dnd مع undo، حذف آمن.
